# Pokenergy

포켓몬과 함께 자연에서 에너지를 모으고, 점차 정착지를 발전시키는 방치형/증분형 웹게임입니다.

## 현재 구현

- 자연 클릭 시 풀/불꽃/물 에너지 중 하나를 무작위로 +0.1 획득
- 풀 1: 이상해씨 출현 — [심록 I] 풀 자연 획득량 +0.1, 클릭마다 노말 +0.1
- 불꽃 4: 파이리 출현 — [맹화 I] 불꽃 자연 획득량 +0.1, 클릭마다 노말 +0.1
- 물 7: 꼬부기 출현 — [급류 I] 물 자연 획득량 +0.1, 클릭마다 노말 +0.1
- 노말 19: 꼬렛 출현 — [몸통박치기] 5초마다 자연 클릭 1회와 동일한 자동 획득
- 자동 획득이 생기면 자연 탐색 횟수 옆에 초당 자동 에너지 기대 획득량 표시
- 자연 / 도감 / 설정 탭
- 브라우저 자동 저장 및 진행도 초기화
