# Pokenergy

포켓몬과 함께 자연에서 에너지를 모으고, 포켓몬이 모이면 마을을 만들어 발전시키는 방치형/증분형 웹게임입니다.

## 현재 마을 건설

- 포켓몬 5마리 발견 시 마을 탭 해금
- 마을 해금과 동시에 초록 풀숲, 모닥불 건설 해금
- 초록 풀숲
  - 비용: 풀 25 + 물 15
  - 효과: 매초 풀 +0.1
- 모닥불
  - 비용: 풀 25 + 불꽃 25
  - 효과: 매초 불꽃 +0.1
- 초록 풀숲 건설 시 촉촉한 풀숲 업그레이드 해금
- 촉촉한 풀숲
  - 비용: 풀 25 + 물 25
  - 효과: 매초 풀 +0.1 및 물 +0.1
  - 초록 풀숲을 대체하는 업그레이드 건물
