# Pokenergy

포켓몬과 함께 자연에서 에너지를 모으고, 포켓몬이 모이면 마을을 만들어 발전시키는 방치형/증분형 웹게임입니다.

## 마을 성장

- 포켓몬 5마리: "포켓몬이 5마리 모여 작은 마을을 이뤘다!"
- 포켓몬 10마리: "포켓몬이 10마리 모여 마을이 커졌다!"
  - 초록 풀숲 추가 건설 해금
  - 초록 풀숲 → 나무그늘의 풀숲 업그레이드 해금
  - 예쁜 꽃밭 건설 해금
- 같은 보금자리는 수량을 합쳐 표시
- 초록 풀숲 추가 건설 비용은 매회 이전의 10배
- 촉촉한 풀숲/나무그늘의 풀숲 업그레이드 비용도 동일 업그레이드 횟수마다 10배

## 신규 보금자리

- 나무그늘의 풀숲
  - 초록 풀숲 1개를 업그레이드
  - 기본 비용: 풀 600, 물 600, 벌레 60, 비행 30
  - 생산: 풀 +0.3/s, 물 +0.3/s, 벌레 +0.1/s, 비행 +0.1/s
- 예쁜 꽃밭
  - 비용: 풀 300, 물 300, 노말 1000
  - 벌레/비행 에너지 획득 확률 +10%
  - 건설 시 세꿀버리 출현
- 세꿀버리 [꿀모으기]
  - 벌레/비행 에너지 획득이 발생하면 해당 획득량 +0.1
