# Pokenergy

포켓몬과 함께 자연에서 에너지를 모으고, 포켓몬이 모이면 마을을 만들어 발전시키는 방치형/증분형 웹게임입니다.

## 현재 구현

- 자연 클릭 시 풀/불꽃/물 에너지 중 하나를 무작위로 +0.1 획득
- 풀 1: 이상해씨 — [심록 I] 풀 자연 획득량 +0.1, 클릭마다 노말 +0.1
- 불꽃 4: 파이리 — [맹화 I] 불꽃 자연 획득량 +0.1, 클릭마다 노말 +0.1
- 물 7: 꼬부기 — [급류 I] 물 자연 획득량 +0.1, 클릭마다 노말 +0.1
- 노말 19: 꼬렛 — [몸통박치기] 5초마다 자동으로 자연 탐색
- 자동 자연 탐색이 생기면 자연 탐색 횟수 옆에 초당 자동 탐색 횟수 표시
- 포켓몬 5마리 발견 시 마을 탭 해금
- 마을 해금과 동시에 초록 풀숲 건설 해금
- 초록 풀숲: 풀 50 + 물 25를 소모해 건설, 매초 풀 에너지 +0.1
- 직접적인 에너지 자동 생산이 생기면 상단 해당 에너지 숫자 옆에 초당 생산량 표시
- 자연 화면 우측에 기록 영역 표시
- 포켓몬 등장, 시스템 해금, 건물 해금/건설을 게임 시작 후 경과시간과 함께 기록
- 자연 / 도감 / 마을(해금 후) / 설정 탭
- 브라우저 자동 저장 및 진행도 초기화
