# Pokenergy

포켓몬과 함께 자연에서 에너지를 모으고, 포켓몬이 모이면 마을을 만들어 발전시키는 방치형/증분형 웹게임입니다.

## 현재 주요 규칙

- 초록 풀숲: 매초 풀 +0.2
- 모닥불: 매초 불꽃 +0.2
- 촉촉한 풀숲: 매초 풀 +0.2, 물 +0.2
- 벌레 10: 구구 — [바람일으키기] 자연에서 비행 에너지 획득량 +0.1
- 노말 210: 깨비참 — [쪼기] 자연에서 10% 확률로 비행 에너지 +0.1
- 벌레 13: 뿔충이 — [벌레의 알림] 자연에서 벌레 에너지 획득량 +0.1
- 풀/물/불꽃이 각각 133 이상: 이브이 — [적응력] 자연 탐색이 풀/물/불꽃 중 랜덤 1종 획득에서 3종 모두 확정 획득으로 변경
- 캐터피와 뿔충이 효과는 합산되며, 구구와 깨비참 효과도 합산
