# Pokenergy

포켓몬과 함께 자연에서 에너지를 모으고, 포켓몬이 모이면 마을을 만들어 발전시키는 방치형/증분형 웹게임입니다.

## 현재 구현

- 상단 에너지는 각 에너지를 최초로 획득한 뒤부터 표시되며, 이후 0이 되어도 계속 표시
- 자연 화면 아래에는 아직 출현하지 않은 포켓몬만 표시
- 풀 1: 이상해씨 — [심록 I] 풀 자연 획득량 +0.1, 탐색마다 노말 +0.1
- 불꽃 4: 파이리 — [맹화 I] 불꽃 자연 획득량 +0.1, 탐색마다 노말 +0.1
- 물 7: 꼬부기 — [급류 I] 물 자연 획득량 +0.1, 탐색마다 노말 +0.1
- 노말 19: 꼬렛 — [몸통박치기] 3초마다 자동으로 자연 탐색
- 풀 10: 캐터피 — [인분] 자연 탐색 시 10% 확률로 벌레 에너지 +0.1
- 총 자연 탐색 560회: 망키 — [할퀴기] 3초마다 자동으로 자연 탐색
- 꼬렛과 망키의 자동 탐색은 합연산
- 벌레 10: 구구 — [쪼기] 자연 탐색 시 10% 확률로 비행 에너지 +0.1
- 포켓몬 5마리 발견 시 마을 탭 해금
- 마을 해금 기록: "포켓몬이 모여 마을을 이루었다!" 다음 줄에 "▶ 마을 탭 해금"
- 초록 풀숲: 풀 50 + 물 25를 소모해 건설, 매초 풀 에너지 +0.1
